# DS-05 — Объединение насыщенностей 400 и 500

**Рабочая ветка:** `work/design-system`  
**Точка отсчёта:** [`f32d66f2d9cb6c578c10a1fe7d5a94843caf97f3`](https://github.com/rrpdsgn111126/wallet-ui-prototypes/commit/f32d66f2d9cb6c578c10a1fe7d5a94843caf97f3).  
**Нормативное правило:** `docs/UI_PATTERNS.md` → «Типографика и цвета: единый источник».

## Принятое изменение

Для текстовых стилей **с кеглем до 20 px включительно** прежние веса 400 и 500 объединены в **400**. Вес **600** оставлен для кнопок, заголовков и сильных акцентов. Размеры, интервалы, цвета, HTML-структура и бизнес-логика этой задачей не изменялись.

- Общий CSS кошелька, банковские стили, CSS UI Kit и образцов, тестовый TransFi-прототип и QA-панель: во всех малых стилях 500 → 400, включая сокращённую запись `font: 500 …`.
- `tokens/tokens.css`: все 8 ссылок на `--ds-font-weight-500` перенаправлены на `--ds-font-weight-400`; неиспользуемая переменная 500 удалена.
- `tokens/tokens.json`: 8 семантических типов с весом 500 получили 400; стандарт малого текста теперь `[400, 600]`. Исторические ключи вида `*-strong` оставлены как совместимые имена: по ним теперь нельзя судить о фактическом выделении.
- Загрузку ресурса Inter 500 в `@font-face` **не изменяли**: это определение шрифта, не типографический стиль UI. Также сохранён вес 500 у `.key` (24 px): он вне выбранного диапазона и должен обсуждаться отдельно.
- Веса 700 у графических элементов и размеры свыше 20 px оставлены.

## Область, объём и количественный аудит

**190 CSS-объявлений** веса 500 заменены на 400 в 7 файлах (включая дублирование общего CSS внутри `transfi-remittance/index.html`). Дополнительно: 8 типографических токенов, описание правила, аудит.

| Показатель | До | После (ожидаемое значение) |
|---|---:|---:|
| Набор утверждённых весов малого текста | 400 / 500 / 600 | 400 / 600 |
| CSS-объявления 500 для малого UI (по исходному статическому аудиту) | 142 | **0** |
| CSS-объявления 400 для малого UI (по исходному статическому аудиту) | 105 | **247** |
| CSS-объявления 600 | 211 | 211 |
| Исключения 700 (графика) | 3 | 3 |

Для вычисленных стилей UI Kit исходная проверка показывала 125 сочетаний: **400 — 42; 500 — 43; 600 — 40**. Суммарное количество сочетаний после изменения может уменьшиться, если одинаковые стили схлопнутся. Текущие данные нужно брать из нового CI-отчёта.

## Контроль

`tests/design-system/font-weight-audit.mjs` теперь возвращает ошибку при любом весе, кроме 400/600, в вычисленных типографических стилях компонентов с кеглем до 20 px. Отдельно ищет объявления 500 в исходниках, проверяет политику JSON-токенов и отсутствие `--ds-font-weight-500`.

Проверять результат нужно по опубликованному **изолированному** UI Kit и тестовому прототипу в `preview/design-system/`. Никаких исходников `main` или `work/prototype` не изменять. Ручная проверка длинных строк, денежных сумм и редких состояний всё ещё нужна даже при успешном Playwright.
