## Объём первой нормализации

По статическому преобразованию CSS в исходных файлах изменено **317 объявлений размеров**, включая повторяющиеся правила в общем CSS и во встроенном CSS прототипа, а также один компонент с самостоятельным стилем. Отдельно нормализованы **5 CSS-объявлений** в тестовой панели `transfi-qa-panel.js`. Дополнительно исправлены **2 запасных значения `var(--pr-b, 17px)` → `18px`**. Пересмотрены **8 семантических типографических ролей** в `tokens/` (часть из них использует общие размерные переменные). Это количество **CSS-объявлений, не число уникальных компонентов и не число видимых элементов**.

Оставлены как осознанные исключения заголовки меньше 20 px (`.bempty b`, `.ir-t`, `.ce-t`, `.ve-sdk-t`, `.tg h4`, `.apiBox h2`), графический знак `.tf-currency-check`, денежные суммы, SVG-графика, печатные документы в pt и размеры от 20 px. **Исключения не означают, что они утверждены как конечная шкала заголовков**: это отдельный будущий этап.

## Контроль в следующих изменениях

1. Сравнить изменённые файлы и коммиты с закреплённым исходным SHA, не с изменяющейся веткой `main`.
2. Запустить `node tests/design-system/typography-audit.mjs <baseline-dir> <current-dir>`: получить количественную таблицу размеров и перечень новых нарушений.
3. Запустить `node tests/design-system/qa.mjs <baseline-dir> <current-dir>` в среде с Playwright и Chrome. Просмотреть созданные кадры «до», «после» и diff, включая 390/430 px и десктоп.
4. Проверить доступность UI Kit именно из этой ветки: GitHub Pages по основному URL показывает `main`, а не этот результат.

**Ограничения:** автоматический статический аудит не охватывает все значения, назначаемые JavaScript во время выполнения, canvas-текст, полное поведение длинных локализаций или визуальную субъективную иерархию. После успешных автоматических проверок всё равно требуется визуальное подтверждение экранов. Отсутствие нарушений кеглей само по себе не доказывает отсутствие переполнений и регрессий.
