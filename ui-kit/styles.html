Токены

Цвета — переменные со .phone (светлая) и html.dark (тёмная) из живого CSS. Слева в паре — светлая, справа — тёмная. * — в светлой значение не объявлено и стоит запасным в var(--x, …). Файлы: tokens/tokens.css, tokens/tokens.json.

Семантические цвета

Текстовые стили

Шрифт и кегли

Текстовые стили в компонентах: в сводной таблице ниже каждая типографическая комбинация показана один раз, с перечнем использующих её компонентов и семантических алиасов; в карточках показаны место применения и фактические значения размер / line-height · насыщенность. Данные считываются из отображаемого образца. «Использует токен» означает проверенную CSS-зависимость; «Совпадение, без привязки» — совпадение параметров без доказанной зависимости; «Локальный стиль» — отсутствие подходящего общего стиля. Для банковских образцов учитываются реальные поля из вложенного экрана.
