## Как открыть

1. Двойной щелчок по `ui-kit/index.html` — витрина в браузере (Chrome, Safari). Интернет не нужен.
2. Один компонент отдельно — `components/<имя>.html`; тёмная тема — `components/<имя>.html#dark`.
3. Листы для дизайнера без браузера — папка `sheet/` (PNG, по листу на группу).
4. Если браузер не пускает файлы с диска — в папке запустить `python3 -m http.server 8000`
   и открыть `http://localhost:8000/ui-kit/` (UI kit) или `http://localhost:8000/` (прототип).

## Откуда что взято

- **CSS** — первый `<style>` собранной страницы. В исходниках это `src/alt.py` (общий CSS)
  плюс `APP_CSS` и стили экранов из `src/app.py`, `src/screens_card.py` и др.; порядок склейки —
  `src/app.py:16674`.
- **Разметка из страницы** — снята как есть, со скриптом выключенным: шапки, кнопки, поля,
  шторки, ПИН, баннер, карта и т. д.
- **Разметка, которую рисует скрипт** — получена вызовом тех же функций кошелька на
  выдуманных данных: строки истории `opRow`, книжка `bookRow`, список стран `veList`,
  код из письма `otpCells`, кружки категорий `catFill`, QR `drawQR` (матрицу считает
  `src/qrcode`, в коде слово «alt.vu demo»). Системный баннер и строки шторки сетей —
  по шаблону `sysBanner` и `netPickOpen` с иконками самого кошелька.
- **Файл и строка** — у каждого компонента на витрине и в комментарии в начале
  `components/<имя>.html`. Номера строк — на коммит `ae501917`.

## Что добавила витрина (в продукте этого нет)

1. «Мини-экран» с краями — у шторок, тоста и нижнего меню: им нужен низ или верх экрана.
2. Подписи состояний над каждым куском.
3. Нажатое состояние: каждое правило кошелька с `:active` повторено с классом `.ds-press`
   (`showcase/states.css`, тело правила то же).
4. `showcase/specimen.css` снимает «прибитую» страницу и рамку телефона, которые кошелёк
   ставит на широком экране. Сам компонент не трогает.
5. Там, где состояние ставит скрипт, сделано то же руками: клавиша Face ID показана
   (скрипт снимает с неё `hidden`, без биометрии гасит классом `.off`), поле адреса — на две
   строки (высоту под адрес ставит скрипт).

## Токены

- Цвета — ровно переменные с `.phone` (светлая) и `html.dark` (тёмная). Лайм `#cbf14a`,
  оправа `#e9ecf0` / `#232221`, нейтральные, смысловые, тени и стекло, девять категорий трат.
- Звёздочка на витрине: в светлой теме значение не объявлено и стоит запасным в
  `var(--x, …)` (`--surface`, `--sh-1`, `--sh-2`, `--glass`, `--line` и др.). В живом CSS
  у `--sh-1` запасных несколько (`0a`, `0d`, `0f`, `10`) — в токены взято самое частое.
- Шрифт, шаг 12, поля 16, радиусы, тени, размеры в живом CSS стоят числами в правилах.
  В `tokens.css` им даны имена `--ds-*`, значения взяты из тех же правил.

## Правила, которые видно на витрине

1. Выбранное — серая плита `--n100` и текст плотнее, **без обводки** (нижнее меню, строка
   шторки). Обводку Ник убрал 28.09.2026.
2. Исключение кошелька: выбранный чип фильтра — лайм, на экране фильтров нет главной кнопки.
3. На лайме знак и текст чёрные (`--brand-ink`).
4. Знаки монет, сетей и alt.vu — файлами, 60 % круга-оправы `--coin-plate`.
5. Лайм — одно главное действие на экран.

## Чего здесь нет

- iOS и Android — не входят (у них SF Pro и родные компоненты; токены те же).
- Админка, лендинг, `alt.vu/card`, вайт-лейблы — не входят. Бренд — только alt.vu.
- Движение (выезд шторки, вращение кольца) — показано статикой.
- Состояний, которых нет в живом CSS, нет и здесь: например, у строки шторки `.m` нет
  «нажато», а «выключено» у сегментов есть только у кнопочной разметки (`.seg button[disabled]`).
- Данные выдуманы: «Анна», «Anna K.», адрес `TDemoAddr…`, суммы. Настоящих клиентов,
  ключей и секретов нет — проверено поиском по архиву.

## Как пересобрать после выкатки

Нужны `~/Desktop/ALT.VU-server` (только читается) и Python с Playwright.

```bash
cd ~/Desktop/ALT.VU-uix/components-alt-vu-1110 && python3 build/harvest.py && python3 build/build.py && python3 build/check.py
```

`check.py` открывает витрину на 1440 и 390 точках, ищет съезд по ширине и ошибки в
консоли (в том числе внутри каждого окна показа) и заново снимает `sheet/`.
